## Question

在信息架构与关键交互定形后，建立专属移动视觉体系，确保不是桌面 UI 缩窄版：

1. 视觉基调：阅读型产品的纸感/克制/专注；品牌色、语义色、深浅主题。
2. 字体与排版：中文正文字体、字号阶梯、行距、段距、标题层级；系统字体与内嵌 TTF 取舍（包体限制）。
3. 组件：移动顶栏、底部 tab、书卡、章节列表、sheet、toast、任务状态、diff 卡片、实体卡、图片卡。
4. 触控：最小点击面积、手势反馈、按压/加载/禁用状态、空态/错误态。
5. 产出高保真关键屏（书架、阅读器、修复审核、实体/插图、设置）和 design tokens。

产出：移动视觉规范 + 关键屏原型，可直接指导 Taro 组件实现。

## Resolution

改道决议：视觉体系以 H5 实现中的 mobile.css 落地（复用 :root token + 触控规范），本票关闭。
