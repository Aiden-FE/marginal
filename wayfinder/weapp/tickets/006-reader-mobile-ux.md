## Question

web 端是「CSS 多栏分页仿真」。小程序移动阅读器的交互模型要重设计，先钉：

1. 阅读形态：连续滚动流 vs 横向分页仿真 vs 纵向整屏翻页——结合 001 的排版能力，哪个适合长文小说、耗电/卡顿、字号自适应。
2. 翻页与进度：上下滑动/点按左右翻页/滑到哪读到哪；进度条/页码呈现；回忆上次位置。
3. 排版控件：字号阶梯、行距、字体（系统 vs 内嵌）、深浅主题、夜间模式。
4. 图文混排：插图在文本流中的位置与样式（inline / 段落间大图）；「点击段落 → 在此处配图」在触屏的入口（长按段落？选中文本？工具栏）。
5. 触控导航：点按呼出/隐藏工具栏（顶部书名、底部页码）、safe-area、防误触。
6. 性能：长章节渲染、内存、滚动流畅度（虚拟列表/按需注入）。

产出：阅读器移动交互原型（草图/静态页/关键交互说明），供视觉与实现参考。

## Resolution

改道决议：H5 阅读器采用「连续纵向滚动 + 段落间插图 + 浮层工具栏」，直接继承本票原型问题；由 H5 实现落地。
