## 修复

### 1. 双重跨章检测路径
新增 [cross_chapter_scroll_controller.dart](apps/marginal/lib/features/reader/cross_chapter_scroll_controller.dart)：

- **`CrossChapterScrollController`**：自定义 `ScrollController`，通过覆写 `createScrollPosition` 创建 `_CrossChapterScrollPosition`。
- **`_CrossChapterScrollPosition`**：覆写 `goBallistic(velocity)`——这是 Flutter 框架把「拖拽松手产生的 fling」转给惯性活动的标准入口。在 fling 起点处于边界（`pixels ≈ minScrollExtent` 或 `pixels ≈ maxScrollExtent`）时，触发 `onEdgeFling(velocity, pixels, min, max)` 回调。

`reader_page.dart`：
- 字段：`final ScrollController _scrollController` → `CrossChapterScrollController`。
- `initState` 注册 `_scrollController.onEdgeFling = _onEdgeFling`。
- 新增 `_onEdgeFling(velocity, pixels, min, max)`：速度 ≥ 500 px/s 且在边界时调 `_tryCrossChapterByDirection(±1)`。正向 fling 在章末 → 下一章；负向 fling 在章首 → 上一章。
- `OverscrollNotification` 路径保留作为兜底，阈值从 `0.12 × viewport` 降到 `0.05 × viewport`（约 30px@600h），长拉超界时也能命中。

这套组合在 iOS BouncingScrollPhysics / iOS ClampingScrollPhysics / Android ClampingScrollPhysics / Flutter Web HTML renderer 下都能工作，因为 `goBallistic` 是物理无关的边界 fling 入口。

### 2. 「点顶栏热区回上一章 → 章末」回归保护

`reader_page_test.dart` 第 208 行已存在 `上部热区在章首向上翻页回退到上一章章尾`，断言 `scrollOffset(tester), greaterThan(0), reason: '落在上一章章尾'`。本次 `flutter test 161/161` 持续通过——这是行为正确性的锁。
